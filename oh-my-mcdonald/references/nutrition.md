# 本餐分析依据

按实际选择的套餐子项和数量，逐项匹配 MCP `list-nutrition-foods` 标准份量营养表。已验证字段包括 kcal、蛋白质/脂肪/碳水化合物 g，以及钠/钙 mg。返回为带行数和字段头的 TOON 表，脚本校验行数和列数。

食品名称和规格精确匹配。重复且相同的数据可合并使用，重复但营养值冲突的记录标为未匹配。未匹配餐品列在结果中，合计标题改为“已匹配部分合计”。`nutrition-aliases.json` 保留为人工核实同规格名称后再增加的映射，默认无别名。

一般成人的食物多样性覆盖谷薯、蔬菜水果、畜禽鱼蛋奶、豆类等。单餐画面展示已知数据，其他餐搭配完整水果、蔬菜、全谷物、奶或豆类，具体种类由当天其余餐决定。玉米杯主要补充谷薯类，汉堡配菜的少量生菜没有按一份蔬菜计数。

含糖饮料替换为水或无糖饮品时，以相同杯型和官方营养数据比较能量与碳水变化。肉类和炸物的替换也需使用可售详情，重新核价。营养脚本输出基础搭配方向；对话客户端根据本餐匹配结果解释具体差异。

依据：

- 中国营养学会，《中国居民膳食指南（2022）》，2022年：[出版说明与核心准则](https://www.cnsoc.org/bookpublica/0522202019.html)。
- 国家卫生健康委，2025-05：[“健康饮食、合理膳食”核心信息](https://www.nhc.gov.cn/sps/c100088/202505/6b7a718abd4848e8a3e98fc561a8858b.shtml)，强调增加蔬菜水果、全谷物和水产品，阅读糖、盐与脂肪标签。
- 麦当劳 MCP 营养表：每次生成图片时主动查询，查询时间随图保存。
